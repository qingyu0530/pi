## 1. 项目目标与结构

用 Rust 重写 Pi Agent，同时通过项目学习 Rust（对照 C++ 概念）。仓库根下现在是同级目录：

- `pi/`：原版 TypeScript monorepo（`packages/ai`、`packages/agent`、`packages/tui`、`packages/coding-agent`）。
- `pi-rust/`：Rust 重写版，独立 cargo workspace，四个 crate：

```text
pi-rust/
├── Cargo.toml            # workspace，edition 2024，rust-version 1.85，禁止 unsafe
├── Cargo.lock
├── rust-toolchain.toml
├── rustfmt.toml
├── crates/
│   ├── pi-ai/            # 模型/消息/协议/Provider/注册表
│   │   └── data/models.json
│   ├── pi-agent-core/    # Agent 运行时/工具/会话/压缩
│   ├── pi-tui/           # 终端渲染
│   └── pi-coding-agent/  # 可执行程序 pi
└── docs/
```

## 4. `pi-ai` 模块

- `content.rs`：`TextContent` / `ThinkingContent` / `ImageContent` / `ToolCall`；按来源限制的 `UserContent` / `AssistantContent` / `ToolResultContent`。
- `message.rs`：`UserMessage`、`AssistantMessage`（usage/cost/stopReason/diagnostic/deferred）、`ToolResultMessage<TDetails>`、`ConversationMessage`。
- `context.rs`：`Tool`、`Context`、`ConstrainedSamplingConfig`。
- `event.rs`：`AssistantMessageEvent`（12 种流式事件 + `partial()`）。
- `images.rs` / `cost.rs` / `compat.rs`：图片生成类型、成本类型、兼容配置与路由类型。
- `model.rs`：`Model`、`ImagesModel`、`ModelCompat`、`ThinkingLevel(Map)`、`InputType`；`calculate_cost`。`Model` 用自定义 `Deserialize`：先读顶层 `api`，再把**扁平的** `compat` 派发成对应变体。
- `models.rs`：`ModelRegistry`，数据形状 `{ api: { modelId: Model } }`，`data/models.json` 用 `include_str!` 内嵌；`get` / `models` / `providers` / `models_for_provider`。
- `provider.rs`：`Provider` trait（`stream(model, context, options)`）；`RequestOptions`（`temperature` / `max_tokens` / `reasoning_effort` / `session_id` / `cache_retention`）；`CacheRetention`；`FauxProvider`。
- `api/http.rs` / `api/http_ureq.rs`：`HttpTransport::post` 返回 `Box<dyn Read>`（流式）；`UreqTransport`（连接池 + 120s 超时，rustls + gzip）。
- `api/openai_compat.rs`：`ResolvedOpenAICompletionsCompat` + `detect` / `resolve`。
- `api/openai_completions.rs`：请求构造（compat 驱动的字段：max_tokens 名、store、developer 角色、strict 工具、thinking、路由、prompt cache、cache_control）、chunk 解析、`ChatCompletionStream` 聚合、`OpenAiCompletionsProvider`、`aggregate_sse`。
- `api/anthropic_messages.rs`：`ResolvedAnthropicCompat`、`MessagesRequest`、`AnthropicStream` 聚合、`AnthropicEventStream`（基于 `Box<dyn Read>` 的**边读边解析** `Iterator`）、`AnthropicMessagesProvider`。

## 5. `pi-agent-core` 模块

- `lib.rs`：`Agent`（provider/model/system_prompt/tools/messages/options）；`run_once`、`run`/`run_loop`（最多 32 轮）、`execute_tool_calls`、`maybe_compact`；`with_system_prompt` / `with_options`。
- `tool.rs`：`AgentTool` trait、`ToolResult`、`EchoTool`。
- `tools/`：`read`（offset/limit + 截断）、`write`、`edit`（唯一且不重叠替换）、`ls`、`find`（glob）、`grep`（regex）、`bash`。
- `walk.rs`：目录遍历辅助。
- `environment.rs`：`Environment`（`read_file` / `write_file` / `read_dir` / `append_file` / `create_dir_all`）、`DirEntry`、`RealEnvironment`。
- `shell.rs`：`Shell` trait、`ShellOutput`、`RealShell`（`bash -c`，超时轮询，stdout/stderr 并发读避免死锁）。
- `session.rs`：`Entry`（Message/Custom，带 id/seq/parentId/timestamp）、`Session`（`push_message` / `push_custom` / `fork_from` / `entry` / `leaf_id` / `to_jsonl` / `from_jsonl` / `save` / `append_new` / `load`）。
- `compaction.rs`：token 估算、`should_compact`、`plan_compaction`、摘要提示、`compact`。
- `truncate.rs`：头部/尾部截断（行数或字节上限）。
- `event.rs`：`AgentEvent`（run / turn / message / tool 四层）。

## 6. `pi-tui` 与 `pi-coding-agent`

- `pi-tui`：`Renderer`（`write` / `render_line` / `flush`）、`PlainRenderer`、`EventRenderer`（把 `AgentEvent` 增量渲染，文本/思考/工具分别处理）。
- `pi-coding-agent`：
  - `args.rs`：手写参数解析。支持 `--provider`、`--model`、`--api-key`、`--system-prompt`、`--thinking`、`--session`、`--session-dir`、`--continue`/`-c`、`--resume`/`-r`、`--no-session`、`--print`/`-p`、`--list-models [search]`、`--help`、`--version`、`--`。
  - `session_store.rs`：会话目录管理（`list_sessions` / `most_recent_session` / `new_session_path`）。
  - `main.rs`：按参数与环境（命令行 > 环境变量 > 默认）选模型；按 `api` 分派 `OpenAiCompletionsProvider` 或 `AnthropicMessagesProvider`（密钥分别读 `OPENAI_API_KEY` / `ANTHROPIC_API_KEY`）；注册 7 个内置工具；用会话路径作 session id；`run_turn` / `compact_if_needed` / `persist` / `repl`。

## 9. 使用的 Rust 概念（累计）

- 模块系统、`struct`/带数据 `enum`、`match`、trait、`impl`、泛型、默认类型参数。
- 所有权/借用/`clone`/`std::mem::take`；`Box<dyn Trait>` trait object；`RefCell`/`Rc`。
- Serde：`tag` / `untagged` / `flatten` / `rename` / `rename_all` / `default` / `skip_serializing_if`。
- 自定义 `Deserialize`（按另一字段值派发）；`Serialize` 手动实现（扁平写出）。
- `let ... else`、`Option` 组合子（`is_some_and` / `then` / `then_some` / `flatten` / `or` / `map`）、`matches!`。
- 枚举 `#[default]` + `unwrap_or_default`；错误类型 + `Display`。
- 迭代器（`into_values` / `flat_map` / `rev` / `enumerate`）、`BTreeSet` 去重排序、`sort_by`。
- `std::process::Command` + 线程并发读管道 + 超时轮询；`std::io::Read` 流式解析。
- `include_str!` 编译期内嵌数据；类型别名。
- 有状态聚合器（`ChatCompletionStream` / `AnthropicStream`）。
- 闭包作为参数（`impl FnOnce`）做依赖注入（摘要器）。
